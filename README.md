# Helena Novel Reader - Arc 6 Update

Website pembaca novel Helena versi clean/showcase.

Isi:
- Arc 1 sampai Arc 6
- Prologue + Chapter 1 sampai Chapter 255
- Total 256 item baca
- Semua chapter berstatus full chapter
- Reader mode dengan teks rata kanan-kiri, progress baca, pencarian chapter, dark mode, dan pengatur ukuran font.

Cara pakai:
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Upload seluruh folder ke GitHub Pages/hosting bila ingin dijadikan website online.
